# 广东岭南现代技师学院咨询机器人知识库规划

> 状态：规划稿，待补充学校官方数据后转为正式知识库
> 日期：2026-10-30
> 适用对象：广东岭南现代技师学院咨询机器人（`web/public/chat-jishi.html`）

## 1. 前提

仓库中现有的知识库资料（`docs/测试问答/原始知识库文件/`、`docs/测试问答/题目清单-240条.md`）全部针对**广东岭南职业技术学院**（高职），不能直接复用到技师学院。

技师学院在招生对象、培养层次、毕业待遇、资助政策上与高职院校不同，混用会答错关键问题。因此需要单独建设一套知识库。

`web/public/chat-jishi.html:39-107` 已定义六类访客角色：**考生与家长、在校学生、教职工、合作企业、校友、来校访客**。这六类人决定了知识库的覆盖面，其中考生与家长会占绝大多数提问量。

## 2. 建议涵盖的 12 个板块

| 优先级 | 板块 | 要回答的核心问题 | 主要受众 |
|---|---|---|---|
| P0 | 学院概况与办学层次 | 什么性质的学校、国家重点技师学院意味着什么、中级工/高级工/预备技师分别招谁、读几年、在哪个校区 | 全部 |
| P0 | 招生报名与录取 | 招初中生还是高中生、报名条件、时间、方式、材料、录取规则、要不要填志愿 | 考生家长 |
| P0 | 专业与培养 | 有哪些二级学院和专业、每个专业学什么、实训条件、考什么证、订单班/校企班 | 考生家长、在校生 |
| P0 | 收费与资助 | 学费、住宿费、代收费、退费；免学费对象、国家助学金、奖学金、勤工助学 | 考生家长、在校生 |
| P0 | 毕业待遇与升学 | 毕业证和技能等级证是什么、高级工/预备技师对应什么待遇、能否升大专/本科、三二分段和职教高考怎么走 | 考生家长 |
| P1 | 校园生活与到校 | 校区地址、交通、报到流程、宿舍、食堂、校园卡、军训、校历、门禁 | 考生家长、在校生、访客 |
| P1 | 教学与学籍管理 | 课表/教务系统、考试、转专业、休学复学、毕业条件、成绩证明 | 在校生、教职工 |
| P1 | 技能认定与竞赛 | 能考哪些职业技能等级证书、怎么报名、费用、证书查询；竞赛体系和集训 | 在校生、企业 |

| P2 | 校友与档案 | 毕业证明/技能证书补办、档案去向、校友会、返校预约 | 校友 |
| P2 | 机器人边界与兜底 | 能答什么、不能承诺什么、答不了转哪个部门 | 全部 |

## 3. 技师学院特有的 6 个高风险点

这些是照搬高职资料最容易出错、也最影响信任的地方，知识库必须写死口径：

1. **校名不能混**：技师学院 ≠ 职业技术学院。回答里不要出现“我校大专”“专升本”这类高职话术，除非确指合作项目。
2. **层次与待遇要说准**：中级工、高级工、预备技师班的招生对象、学制、毕业证书类型不同；“高级工班毕业生按大专待遇”这类表述要引用现行政策依据，不能笼统说“包大专”。
3. **招生通道不同**：初中毕业生和高中/中职毕业生的报名方式、录取规则可能完全两套，知识库要分开写，不能合并成一段。
4. **资助政策不能照搬**：中职免学费对象（农村/县镇/城市困难）、国家助学金、奖学金各有条件；生源地信用助学贷款等政策是否适用必须先确认，不能想当然。
5. **不做录取和就业承诺**：不回答“多少分一定能进”“包分配”“保底薪资”；统一为“参考往年情况”“推荐就业/校企合作”。
6. **时效性标记**：招生计划、学费、分数线、校历每年变。每篇文档要带年度、依据和有效期，过期内容应转人工而不是继续答。

## 4. 默认知识库的组织方式

建议按**主题**建文档，而不是按角色建——同一事实会被多类人问，按角色会重复维护。

每篇文档统一模板：

```text
标题（含口语关键词，如“技师学院报名条件”）
一句话结论
适用对象
详细说明（分小节；表格保持完整）
常见问法（5–10 条同义句，提升召回）
办理/联系（部门、电话、地点、时间）
依据与时效（文号/链接/年度）
责任部门 + 更新日期
```

几个具体建议：

- **专业类**：先做一张“专业总表”（专业、层次、学制、招生对象、证书、就业方向），再给每个专业单独一篇，不要只上传整本招生简章 PDF——跨页表格切块后召回质量很差。
- **收费/电话/地址**：用独立结构化表格，字段固定，便于核对和更新。
- **FAQ 对是补充，不是主体**：正文负责准确性，FAQ 负责口语匹配；两者指向同一口径。
- **兜底必配**：每个板块末尾写明“本板块答不了找谁”，机器人未知问题时统一转招生办/对应部门，而不是编造。

## 5. 需要学校提供的 12 项关键数据

1. 学院全称/简称/招生代码
2. 校区地址、邮编、地图
3. 办学层次与学制对照表
4. 2026 年招生对象、报名方式与时间
5. 分专业招生计划
6. 学费、住宿费、代收费
7. 免学费、国家助学金、奖学金政策
8. 毕业证与待遇口径
9. 升学项目及对接院校
10. 实习就业安排
11. 部门电话总表
12. 校历与报到时间

在这些数据到位前，可以先搭**目录、文档模板和 30–50 条高频问答**，具体数字留占位符并标注“待学校确认”，避免把猜测写进知识库。
