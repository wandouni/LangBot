# 部门材料提交模板（一页纸）

> 配套文件：`知识库补全需求清单.xlsx`、`知识库补全需求清单.md`
> 用途：各部门按编号领取任务，按本页要求提交材料；知识库运维组统一入库。

## 一、你要交什么

打开 Excel 的「按部门」Sheet，找到本部门那一段。每一条（如 `G-04 校园卡`）交三样东西：

| 交付物 | 说明 | 示例 |
|---|---|---|
| 1. 正文材料 | 能直接回答用户问题的内容，优先表格 | 《校园卡使用指南》一篇 |
| 2. 一句话结论 | 每个高频问题先给结论，再展开 | “校园卡丢失后先在公众号挂失，再到两校区服务点补办，工本费以学校公布标准为准。” |
| 3. 常见问法 | 5–10 条用户会怎么说，放在文末 | “饭卡丢了怎么办”“一卡通在哪充值” |

同时在 Excel「材料提交模板」Sheet 中回填：文件名称/链接、公开级别、责任人、联系电话、建议入库时间、备注。

## 二、怎么写（直接影响机器人能不能答对）

1. **一篇文档只讲一件事**。宿舍一篇、校园卡一篇、医保一篇；不要把整本学生手册直接上传。
2. **能用表格就别写长段落**。收费、电话、专业、校历、宿舍类型、开放时间、招生计划必须用表格。
3. **每个数字都带口径**：年度、校区、适用对象、专业层次。例如“2026 级、清远校区、四人间，1500 元/学年”。
4. **电话写对外办公电话**，不要写个人手机号；分校区、分部门标注清楚。
5. **流程写清五要素**：谁办、在哪办、带什么、多久办完、找谁问。
6. **政策类写依据和有效期**：文件名、文号、发布日期；没有文号的写“以学校最新通知为准”。
7. **文末放 5–10 条常见问法**，用学生/家长的原话，不要写成公文标题。
8. **标题加入口语关键词**：例如“校园卡（一卡通）充值、挂失、补办”，不要只写“关于一卡通管理的说明”。

## 三、格式与文件

| 项目 | 要求 |
|---|---|
| 文件格式 | 优先 `.docx` / `.md` / `.xlsx`；PDF 必须能复制文字，扫描件不收 |
| 单文件大小 | 不超过 10MB |
| 图片 | 流程图、地图可嵌在文档中；关键信息不要只放在图片里 |
| 命名 | `编号-业务域-学校-版本日期`，例如 `G-04-校园卡-职院-20261106.docx` |
| 编码 | UTF-8 |

平台支持 `.pdf / .doc / .docx / .txt / .md / .html / .zip`，暂不支持直接导入网页 URL；网页内容请另存为文档。

## 四、什么不能交（敏感信息红线）

以下内容**一律不要写进材料**，机器人只给办理入口和经办部门：

- 身份证号、银行卡号、个人手机号、家庭住址、成绩单、录取结果、宿舍号等个人数据；
- 系统账号、密码、后台地址、数据库连接、内部 API 地址；
- 未公开的招生计划调整、人事决定、会议纪要、内部预算与合同；
- 学生心理危机个案、违纪处分个案、医疗个案；
- 其他部门未授权公开的材料。

拿不准的，在 Excel「备注」列写“需确认公开级别”，由知识库运维组和对应部门会签后再入库。

## 五、交给谁、什么时候交

| 阶段 | 时间 | 内容 |
|---|---|---|
| 领取 | 收到清单后 3 个工作日内 | 确认本部门条目、责任人和预计完成时间 |
| 首批（P0） | 2 周内 | A-02、A-03、A-04、B-09、C-01～C-04、D-01、D-03、D-05、E-03、F-04、G-01、G-02、G-04、H-02、K-01～K-04、K-06 |
| 第二批（P1） | 1 个月内 | 清单中标注 P1 的条目 |
| 第三批（P2） | 2–3 个月内 | 清单中标注 P2 的条目 |
| 日常更新 | 按学校约定的复审周期 | 年度数据每年招生季前；政策文件发布后 5 个工作日内；学期数据开学前 |

提交方式：按学校约定的共享目录或 OA 流程提交给知识库运维组；邮件主题写 `知识库材料-部门-批次`。

## 六、回填示例（以校园卡为例）

| Excel 字段 | 回填内容 |
|---|---|
| 编号 | G-04 |
| 业务域 | 校园卡/一卡通 |
| 我方提供材料 | 《校园卡使用指南》、补办流程表、两校区服务点位置与营业时间 |
| 文件名称 / 链接 | `G-04-校园卡-职院-20261106.docx` |
| 文件形式 | Word + 表格 |
| 公开级别 | B（不含充值账号与后台密码） |
| 责任人 | 后勤处 张老师 |
| 联系电话 | 020-XXXXXXXX（对外办公电话） |
| 建议入库时间 | 2026-11-20 |
| 备注 | 补办工本费与挂失生效时间需财务确认 |

## 七、入库后会发生什么

1. 运维组做格式检查、脱敏、切块、入库；
2. 按条目“需补材料”中的关键事实出 10 道测试题，请责任部门确认答案口径；
3. 抽 20% 做“无答案测试”，确认机器人不知道时会转人工，而不是编造；
4. 连续两周看咨询看板：高频未命中会在两周内回补或配置转人工；
5. 材料更新时只需替换原文并改“更新日期”，不要新建重复文档。
