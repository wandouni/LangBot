# 两校公共服务咨询机器人知识库补全需求清单

> 编制日期：2026-11-06
> 数据来源：生产环境 `192.168.31.66:5300` 只读实测（机器人、流水线、知识库、文档清单、快捷提问），仓库内现有资料 `docs/测试问答/`、`docs/技师院知识库/`。
> 适用对象：广东岭南职业技术学院、广东岭南现代技师学院；用于向各业务部门收集材料、补齐机器人能力。
> 配套文件：`知识库补全需求清单.xlsx`（按部门分发）、`部门材料提交模板.md`（部门回填说明）。

## 0. 一页纸结论

**现在能答什么**：招生专业、招生计划、分数线、学费住宿费、新生报到、部分校园生活与部门电话。两校中，职院的知识库更偏“招生资料汇编”，技师院是“12 板块框架稿”。

**最大的缺口**：机器人目前更像“招生咨询机器人”，还不是“公共服务咨询机器人”。在校生每天要用的学籍、考试、校园卡、网络、报修、图书馆、医保、安全，以及教职工、企业、校友的办事指引，基本没有形成可检索的文档。

**最急的 9 件事**（P0）：
1. 事项—部门—办公时间与地点对照表（A-03）。
2. 学年校历与两校区作息时间（A-04）。
3. 校园平面图、楼宇索引与各二级单位办公地点（A-02）。
4. 报到流程、材料份数与补办路径（C-01、C-02）。
5. 绿色通道与资助办理（C-03、B-09）。
6. 教务系统账号找回、补考重修、学籍异动（D-01、D-03、D-05）。
7. 校园卡办理/挂失/补办（G-04）。
8. 宿舍分配、调宿与报修（G-01、G-02）。
9. 心理危机、24 小时报警、失物招领三条安全底线（E-03、H-02）。

**使用方式**：把 Excel 的「按部门」Sheet 直接发给对应部门；部门在「材料提交模板」中回填“能提供什么、文件名/链接、公开级别、责任人”；知识库运维组按模板整理入库并做测试题库验收。

## 2. 清单使用说明

### 2.1 字段说明

| 字段 | 含义 |
|---|---|
| 编号 | 如 `A-01`，部门回填时保留编号即可，不要自行改号 |
| 业务域 | 学校具体业务范围 |
| 典型问题 | 用户真实口语问法，用于判断文档该覆盖到什么程度 |
| 职院现状 / 技师院现状 | **已有**＝有较完整内容；**部分**＝有提及但不足以直接回答；**缺失**＝知识库无对应内容；**不适用**＝两校政策不同，该校不涉及 |
| 需补材料 | **只列知识库目前没有的内容**；已有内容不重复列出，已有但需按年度替换的会在该列注明 |
| 责任部门 | 主责部门；两校部门名称不同的在括号中注明 |
| 公开性 | A 可直接公开；B 脱敏后公开；C 仅给转人工指引 |
| 优先级 | P0 最急；P1 次之；P2 可后补 |

### 2.2 优先级口径

- **P0**：考生家长与新生高频；答错会造成录取、缴费、报到损失；或涉及安全底线；目前缺失或只有模糊表述。
- **P1**：在校生日常高频；影响办事体验；可以转人工，但体验明显下降。
- **P2**：低频角色（校友、企业、教职工）或制度性内容；先给入口和电话即可。

### 2.3 公开性口径

- **A 可直接公开**：官网、公众号、招生简章已发布，或属于公开制度、公开电话、公开流程。
- **B 脱敏后公开**：有内部流程但可以对外说明；必须去掉个人手机号、账号密码、内部系统路径、未公开数据。
- **C 仅转人工**：涉及个人隐私、实时业务查询（成绩、录取结果、宿舍号、个人社保）和内部决策；机器人只给办理入口和经办部门。

### 2.4 材料格式规范

1. **结构化优先**：能用表格的不要写成长段落，尤其是收费、电话、专业、校历、宿舍类型、招生计划。
2. **一篇文档一个主题**：例如“宿舍管理”一篇、“校园卡”一篇；不要把整本学生手册直接上传。
3. **每篇带元数据**：标题含口语关键词、适用对象、责任部门、更新日期、有效期、依据文号/链接。
4. **常见问法 5–10 条**：放在文末，提升口语召回；正文负责准确性。
5. **不要只交 PDF 扫描件**：表格跨页切块后召回质量差；优先 Word/Markdown/Excel，PDF 需可复制文字。
6. **单文件不超过 10MB**；平台支持 `.pdf/.doc/.docx/.txt/.md/.html/.zip`，不支持直接导入网页 URL。

### 2.5 提交与更新

- 各部门按 Excel「按部门」Sheet 领取条目，在「材料提交模板」中回填。
- 知识库运维组统一做格式检查、脱敏、切块、入库、测试题验收。
- 招生、收费、校历、宿舍等年度数据，每年招生季前复审一次；政策类随文件发布即时更新。
- 过期内容统一改为“该项政策已更新，请以最新公告为准”，不得继续输出旧结论。

## 5. 实施路线

### 第一阶段：2 周内（P0，先止血）

- A-02、A-03、A-04：校区归属、部门电话、校历作息。
- B-09、C-01、C-02、C-03、C-04：报到流程、材料、绿色通道、资助、户口档案党团关系。
- D-01、D-03、D-05：教务账号、补考重修、学籍异动。
- F-04：升学路径（专升本/职教高考/三二分段/国际合作）。
- G-01、G-02、G-04：宿舍、报修、校园卡。
- E-03、H-02：心理危机与 24 小时报警。
- 职院 B-01～B-05、B-07 已有较完整内容，按年度更新即可；技师院按“部分/缺失”状态补齐，不占首批全部工作量。

### 第二阶段：1 个月内（P1，覆盖在校生日常）

- D-02、D-06、D-07：选课、毕业、证明。
- E-01、E-02、E-04：请假处分、评优、勤工助学。
- F-01、F-02、F-03、F-06：就业、招聘、实习、离校。
- G-03、G-05、G-07、G-10：食堂、网络、医保、图书馆。
- H-01、H-03、H-04：访客、消防、反诈。
- J-01、J-03、J-05：制度、办事指南、投诉。
- I-05、I-06：校企合作、技能认定。

### 第三阶段：2–3 个月（P2，补齐低频角色）

- B-06、B-10、B-11：特殊类型考生、招生监督、学院介绍。
- E-05、E-06、E-07：党团、社团、征兵。
- F-05：创业扶持。
- G-06、G-08、G-09：快递、场馆、交通。
- H-05：户籍出入境。
- I-01～I-04、I-07、I-08：人事、财务、科研、国际、行政。
- J-02、J-04：信息公开、新闻公告。

### 验收方式

1. 每个 P0 条目按“需补材料”中的关键事实出 10 道测试题，机器人回答与部门口径一致。
2. 抽 20% 条目做“无答案测试”，确认兜底话术和转人工部门正确。
3. 连续两周查看咨询看板：P0 条目相关提问的兜底率应明显下降。
4. 逐份检查知识库文档头部：责任部门、更新日期、有效期齐全。
