## 测试准备

1. 启动后端和前端：

```bash
uv run main.py
cd web && pnpm dev
```

2. 打包并安装「咨询问答看板」插件，然后在插件管理中启用：

```bash
cd plugins/qa-analytics
zip -r ../qa-analytics-0.1.0.lbpkg .
```

在 WebUI 进入「添加扩展」，点击「手动添加」，上传生成的 `qa-analytics-0.1.0.lbpkg` 并确认安装。启用后确认侧边栏出现「插件页面」分组。注意插件包必须用 `.lbpkg` 后缀；`.zip` 会被前端当作技能包处理。
3. 使用有资源管理权限的账号登录，插件页面需要该权限。
4. 准备一个已绑定知识库的网页机器人，打开它的聊天窗口。
5. 按下面顺序提问，用来核对统计结果。只有真正触发知识库检索的提问才会进入看板；纯聊天不计入。

| 会话     | 提问                   |
| -------- | ---------------------- |
| 标签页 A | 护理专业能去哪些科室？ |
| 标签页 A | 学费是多少？           |
| 标签页 A | 宿舍条件怎么样？       |
| 标签页 A | 有没有奖学金？         |
| 标签页 A | 护理专业能去哪些科室？ |
| 标签页 A | 学校地址在哪里？       |
| 标签页 B | 报名截止时间？         |
| 标签页 B | 可以专升本吗？         |

预期：总提问数 8，独立会话数 2，高频问题种数 1（护理问题出现 2 次），词云包含“护理”“学费”，Top10 第一条是护理问题。

6. 分页测试需要 25 条以上数据，可继续重复提问，或由开发预置样例数据。
7. 多 IP / 地区筛选，可用同一局域网的另一台设备访问，或由开发预置样例数据。
