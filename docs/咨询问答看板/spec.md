
# 知识库问答统计和明细看板

时间范围选择，默认近7天，可切换今天、近7天、近30天、全部，切换 Tab 时范围保持。

统计总提问数、独立会话数、知识库召回率和高频问题种数；按回答状态（有证据回答、模型兜底、未命中资料、模型生成失败等）统计数量分布；从最近提问中做中文分词、去掉停用词后提取高频关键词生成词云；按改写后的问题归并统计出现次数最多的 10 个问题并排名。图表加载失败时有提示。提供问答明细查询和访问记录查询。

  问答统计提供问答明细查询，支持按时间、提问关键词、回答状态、访客 IP、地区筛选和分页浏览。可查看单条问答的详情：原始提问与改写后的问题、完整回答，并对问题中的关键词做高亮；同时展示回答耗时、使用的发布版本、访客 IP和地区；还可查看该条问答命中的知识库资料、检索得分和内容摘录，并高亮摘录中与提问最相关的句子，未命中资料时明确提示。

  访问记录提供访客会话查询，可查看每个会话的访问 IP、所在地区、停留时长、问答轮数、首次访问时间、最近活跃时间。

  三个 Tab 在接口失败时展示错误提示，数据加载期间显示加载或占位状态。
