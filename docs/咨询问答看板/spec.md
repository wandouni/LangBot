# 知识库咨询问答看板

提供「问答统计」「问答明细」「访问记录」三个 Tab。时间范围默认近 7 天，可切换今天、近 7 天、近 30 天、全部；切换 Tab 时范围保持，刷新页面后也保持。

**问答统计**：展示总提问数、独立会话数、高频问题种数、平均回答耗时；从最近提问中做中文分词、去停用词后生成词云；按改写后的问题归并，统计出现次数最多的 10 个问题。

**问答明细**：按时间倒序展示问答记录，支持按时间范围、提问关键词、访客 IP、地区筛选和分页。单条详情展示原始提问、改写后的问题、完整回答、回答耗时、访客 IP 和地区，并在问题和回答中高亮当前筛选关键词；没有改写问题时明确提示“未提供改写”。

**访问记录**：按访客会话展示访问 IP、所在地区、停留时长、问答轮数、首次访问时间和最近活跃时间，支持按时间范围、IP、地区筛选和分页。

三个 Tab 在数据加载期间显示加载占位，无数据时显示“暂无数据”，接口失败时展示错误提示和重试入口。

本期不包含：知识库召回率、回答状态分布（有证据/兜底/未命中/失败）、发布版本、命中的知识库资料、检索得分和内容摘录。
