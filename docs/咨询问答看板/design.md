# 知识库咨询问答看板 业务方案

> 对应需求：[spec.md](./spec.md)
> 日期：2026-10-26

## 1. 背景与目标

为知识库问答提供一个管理看板，让运营和管理员能回答四个问题：

- 最近有多少人来问、问了多少次？
- 哪些问题被反复问到？
- 每次回答花了多久？
- 具体某个访客问了什么、回答是什么、来自哪里？

本期以网页嵌入聊天为主要数据来源。其他渠道的问答如经过同一问答流程也会被统计，但 IP、地区、会话停留时长可能为空。

看板采用混合方案：

- LangBot 核心负责采集、保存和查询数据，因为只有核心能拿到访客 IP、知识库返回的改写问题和完整问答。
- 看板界面做成插件页面，安装并启用后出现在侧边栏「插件页面」分组下，便于独立发布和升级。

## 2. 使用角色

| 角色 | 关心什么 |
|---|---|
| 运营 / 管理员 | 提问量、访客数、热点问题、整体回答速度 |
| 客服主管 | 按关键词、IP、地区查具体问答和访客会话 |
| 技术支持 | 定位慢回答、异常提问和特定访客的问题 |

## 3. 功能需求

### 3.1 入口与时间范围

- 安装并启用看板插件后，侧边栏「插件页面」分组下出现「咨询问答看板」入口。
- 支持：今天、近 7 天、近 30 天、全部。
- 默认近 7 天。
- 顶部可选择当前 Workspace 下的机器人，默认「全部机器人」；三个 Tab 都按所选机器人过滤。切换 Tab 或刷新页面后，机器人和时间范围都保持。

页面分为三个 Tab：**问答统计**、**问答明细**、**访问记录**，默认打开「问答统计」。

### 3.2 问答统计

展示四项指标：

- 总提问数。
- 独立会话数。
- 高频问题种数。
- 平均回答耗时。

展示两个榜单：

- 词云：对最近提问做中文分词、去停用词，按词频展示；有改写问题时优先使用改写后的文本。
- Top10 问题：按改写后的问题归并，按出现次数从高到低排名。

### 3.3 问答明细

列表：

- 按时间倒序展示时间、问题、耗时、IP、地区。
- 支持按时间范围、提问关键词、访客 IP、地区筛选。
- 支持分页。

单条详情：

- 原始提问。
- 改写后的问题（没有时明确提示“未提供改写”）。
- 完整回答。
- 提问关键词在问题与回答中高亮。
- 回答耗时、访客 IP、地区。

### 3.4 访问记录

按访客会话展示：

- 访问 IP、地区。
- 停留时长。
- 问答轮数。
- 首次访问时间、最近活跃时间。

支持按时间范围、IP、地区筛选和分页。

### 3.5 加载、空数据与异常

- 数据加载期间显示加载占位。
- 无数据时显示“暂无数据”。
- 三个 Tab 在接口失败时显示错误提示和重试入口。
- 统计区加载失败时只影响统计内容，问答明细和访问记录仍可单独打开和重试。

## 4. 业务规则与口径

| 项目 | 口径 |
|---|---|
| 总提问数 | 时间范围内实际触发知识库检索的提问；纯聊天不计入；检索后回答失败或中断仍计入 |
| 独立会话数 | 同一聊天窗口内多次提问算一个会话；刷新不新增，新开窗口新增 |
| 高频问题种数 | 忽略空格、标点差异后，出现 2 次及以上的不同原始问题数量 |
| Top10 归并 | 优先按改写后的问题归并；没有改写时按原始问题；忽略空格、标点差异 |
| 平均回答耗时 | 从用户发出提问到回答完成的平均时间；失败的提问只统计已产生的耗时 |
| 停留时长 | 从首次访问到最近活跃的时间 |
| 问答轮数 | 该访客会话在时间范围内的提问次数 |
| 时间范围 | 今天按访客本地自然日；近 7 天/近 30 天为最近 7×24/30×24 小时；全部为所有历史 |
| 改写问题 | 由知识库检索插件提供；明细中未提供时显示“未提供改写”，统计归并时回退原始问题 |
| 地区 | 依赖离线 IP 归属地库；未启用或无法识别时显示未知；本地/内网地址显示“本地网络” |

## 5. 方案边界与分工

### 5.1 需要改 LangBot 现有源码

| 改动位置 | 改动目的 | 边界 |
|---|---|---|
| 问答流程 | 在每次提问开始和结束时通知看板采集模块 | 不改变回答结果、不阻塞问答 |
| 网页聊天入口 | 记录访客 IP，并随会话传递 | 不改变聊天协议和页面行为 |
| 知识库检索调用 | 读取插件返回的改写问题 | 不改变检索结果和排序 |
| 插件页面宿主 | 由核心识别看板插件页面请求并返回本 Workspace 的只读数据；让插件页面在刷新后恢复时间范围 | 不改变现有插件页面的权限、沙箱和展示规则，不新增 SDK 接口 |

### 5.2 自己实现

**核心新增**

| 模块 | 内容 |
|---|---|
| 问答分析采集 | 汇总每轮问答、访客会话、耗时、IP/地区 |
| 分析数据存储 | 新增看板专用的数据存储和升级脚本，不改现有监控数据 |
| 看板查询服务 | 提供统计、词云、Top10、明细、详情、访问记录查询 |
| 插件只读查询接口 | 只允许看板插件读取本 Workspace 的看板数据，不提供写操作 |
| 分词与地区 | 中文分词、停用词、关键词提取、IP 归属地解析 |
| 配置与清理 | 看板开关、保留期、IP 打码等运营配置 |

**看板插件新增**

| 模块 | 内容 |
|---|---|
| 页面与交互 | 三个 Tab、时间范围、筛选、分页、详情弹窗、加载/空数据/异常状态 |
| 词云与 Top10 展示 | 在插件页面内完成词云和榜单渲染 |
| 页面数据请求 | 页面只向宿主声明查询意图，由核心的看板查询服务返回结果；插件不直接访问数据库或核心 HTTP 接口 |
| 打包与安装 | 插件清单、页面资源、版本与启用状态 |

### 5.3 不改动 SDK 与插件运行时

- 看板插件只用现有的插件页面能力：侧边栏入口、iframe 页面、主题/语言同步、页面 API 请求。
- 核心按插件身份识别看板页面请求，复用自己的登录、Workspace 和查询服务，不新增跨仓库动作或客户端方法。
- 因此看板可以独立发布，不需要与插件 SDK 或插件运行时同步升级。

### 5.4 直接复用，不改

| 能力 | 用途 |
|---|---|
| 登录、权限、Workspace | 控制谁能看、只能看本 Workspace 的数据 |
| 插件页面容器 | 侧边栏「插件页面」分组、iframe 加载、主题/语言同步、页面请求转发 |
| 网页嵌入聊天 | 访客会话入口 |
| 知识库与检索插件 | 回答和改写问题来源 |
| 现有监控 / 会话数据 | 独立运行，不依赖，也不修改 |
| 页面样式与渲染 | 插件页面用 HTML/CSS 完成词云、条形榜和表格展示，不引入额外图表依赖 |

## 6. 模块划分

| 模块 | 归属 | 类型 | 职责 |
|---|---|---|---|
| 网页嵌入聊天 | LangBot 核心 | 现有 | 建立访客会话，提供 IP 和会话标识 |
| 问答流程 | LangBot 核心 | 现有 | 执行一次完整问答，提供开始/结束时机 |
| 知识库检索插件 | 插件生态 | 现有 | 返回回答依据，可选返回改写后的问题 |
| 问答分析采集 | LangBot 核心 | 新增 | 把一次问答和访客会话整理成看板数据 |
| 分析数据存储 | LangBot 核心 | 新增 | 保存问答记录和访问记录 |
| 看板查询服务 | LangBot 核心 | 新增 | 统计、筛选、分页、详情查询 |
| 插件页面只读接口 | LangBot 核心 | 新增 | 识别看板插件页面请求，返回本 Workspace 的只读查询结果 |
| 分词与地区 | LangBot 核心 | 新增 | 关键词提取和 IP 归属地解析 |
| 看板插件页面 | 看板插件 | 新增 | 展示统计、明细、访问记录 |
| 插件页面容器 | LangBot WebUI | 现有 | 承载插件页面、同步主题/语言、转发页面请求 |
| 登录 / 权限 / Workspace | LangBot 核心 | 现有 | 认证、授权、租户隔离 |

## 7. 模块关系与数据流

```text
[网页嵌入聊天] ──访客/IP──┐
                          ▼
[问答流程] ──提问/回答──> [问答分析采集] ──写入──> [分析数据存储]
      │                        ▲                        │
      └──检索──> [知识库插件]  │                        ▼
                (改写问题)     │                  [看板查询服务]
                               │                        ▲
                    [分词与地区]                        │
                                                         │
[看板插件页面] ──页面请求──> [WebUI 插件页面容器] ──转发──> [核心插件页面入口]
                                                         │
                                                         └──仅看板插件：调用看板查询服务
```

关系说明：

- **问答分析采集是中心**：从网页聊天拿访客信息，从问答流程拿问题、回答和耗时，从知识库插件拿改写问题。
- **分析数据存储只服务看板**：与现有监控、会话摘要并行，互不依赖。
- **看板查询服务依赖存储和权限**：所有查询限定在当前 Workspace。
- **核心插件页面入口是唯一读通道**：识别看板插件身份后才调用看板查询服务；其他插件仍走原有页面 API 转发。看板插件不直接访问数据库，也不直接调用核心 HTTP 接口。
- **看板插件页面只负责展示**：不做统计口径计算，所有数据来自核心查询。
- **采集与展示解耦**：看板插件未安装、未启用或被停用，只影响页面入口和查询，不影响核心按配置继续采集。
- **插件页面容器只提供运行环境**：负责登录态、iframe、主题/语言和时间范围记忆，不参与业务逻辑。
- **登录 / 权限 / Workspace 是横切能力**：插件页面入口和核心查询都会校验。

## 8. 依赖与约束

- **安装与启用**：看板页面依赖插件已安装并启用；停用后入口消失，重新启用后恢复，历史数据不丢失。
- **权限**：插件页面沿用现有插件页面权限，仅具备资源管理权限的用户可访问；查询只返回当前 Workspace 的数据。
- **版本兼容**：看板插件需要与包含看板查询能力的 LangBot 版本配套；旧版核心无法返回看板数据时，页面显示失败提示和重试入口，不展示错误数据。
- **iframe 限制**：插件页面运行在隔离沙箱中，不能直接读取宿主页面、浏览器本地存储或核心 HTTP 接口；页面请求经宿主转发，主题、语言和时间范围由宿主同步和保存。
- **运行时可用性**：看板查询依赖插件已安装、已启用且运行时可用；不可用时页面显示失败提示和重试入口。
- **改写问题**：依赖知识库检索插件返回；统计归并时回退原始问题，明细中提示“未提供改写”，不影响其他功能。
- **地区**：依赖离线 IP 归属地库；默认关闭，未配置时地区显示未知，本地/内网地址显示“本地网络”。不调用第三方在线服务。
- **中文分词**：内置中文分词和停用词；分词组件不可用时降级为双字切分。
- **会话口径**：沿用网页聊天的窗口会话；刷新不新增，新窗口新增。
- **隐私**：列表默认对 IP 打码，详情按权限展示完整信息；数据按保留期自动清理；日志不记录完整 IP 和问答内容。
- **性能**：看板查询不能影响正常问答；数据量大时词云按最近样本计算。
